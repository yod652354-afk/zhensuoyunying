# DeepSeek 总开发指令

你正在维护现有 ClinicOS 项目，并将它兼容升级为 RevOS。

## 绝对约束

1. 先阅读现有代码，不根据README猜测实现。
2. 不重写系统，不创建平行后端，不删除已有数据和功能。
3. 保留 FastAPI、SQLAlchemy 2、Pydantic v2、Alembic、Vue 3 技术栈。
4. 所有数据库变更使用新的 Alembic migration，不修改既有初始migration。
5. 所有业务查询和写入必须由服务端认证上下文强制执行organization/store隔离。
6. 不信任客户端传入的organization_id、customer_id、审核状态、发送状态和支付结果。
7. 未审核ExecutionPlan不得执行；批准后的内容改变必须重新审核。
8. DNC、投诉、未授权、频控必须在实际发送前再次检查。
9. 对照组不得生成真实外部触达。
10. AI只能从系统允许的动作和策略中选择，不能修改合规规则、价格和优惠。
11. 文本/图片生成使用可替换Provider，不引入复杂Agent框架。
12. 所有外部调用必须有超时、幂等、错误分类、日志脱敏和安全兜底。
13. 一次性完成本工程包要求的全部RevOS能力，同时交付测试、迁移说明、回滚方式和风险说明。
14. 开发过程中可按依赖顺序设置内部检查点，但不得将其解释为分期交付；最终统一运行现有43项测试和全部新增测试。
15. 不做本任务之外的重构、UI美化、全局重命名和依赖升级。
16. 必须读取`05-产品决策记录.md`；如旧规格与最新有效决策冲突，以最新有效决策为准，不得同时实现互相冲突的旧方案。
17. `05-产品决策记录.md`中“待确认事项”不得自行假设或开发；遇到影响业务结果的不确定选择，必须暂停该选择并请求项目负责人确认。其余已明确且不受影响的工作可以继续。

## 开发开始时必须输出

```text
现有实现事实
本任务目标
涉及文件
数据兼容策略
权限和租户风险
测试计划
回滚方式
```

## 一次性开发结束时必须输出

```text
修改文件
新增migration
新增/变更接口
事件变化
测试命令和结果
安全检查
兼容性说明
未完成项
下一步建议
```

## 禁止声明

未完成真实企微联调、真实门店数据和Treatment/Holdout验证前，不得声称：

- 已实现自动运营；
- 已实现增量收入；
- 已实现AI学习；
- 已生产可用；
- 已完成多租户安全。
