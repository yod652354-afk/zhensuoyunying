# RevOS 修复新增测试与验收门禁

## 1. 对照组测试

- 对照组禁止生成Content/Task/Touch；
- 对照组自然预约、到店、支付仍记录Outcome；
- Treatment 20%、Control 10%时增量率为10个百分点；
- 两组自然支付同为10%时增量为0；
- 退款正确冲减两组净收入；
- 对照组Outcome不关联执行Action。

## 2. 调度端到端测试

- 每日任务不直接创建外部触达Task；
- 每个组织均被处理；
- 同客户重复运行不重复Opportunity/Plan；
- DNC、投诉、未授权不会进入待审核；
- 未审核不会进入发送；
- 单租户失败不影响其他租户；
- 重启后未完成Job继续执行。

## 3. 重复归因测试

- 一个客户同时存在三个机会，一笔支付只产生一个primary attribution；
- 非主机会不得重复WON；
- 归因窗口外支付不匹配；
- Touch发生前的支付不匹配；
- 退款能找到原支付和原primary attribution；
- 无法匹配进入人工队列。

## 4. 前端认证测试

- 源码和dist中不存在`dev-key-change-me`；
- 未登录不发送X-API-Key；
- 未登录访问受保护页面跳登录；
- JWT过期清理会话；
- 上传和导入只使用JWT。

## 5. 数据库并发测试

- 并发Detector只产生一个活动Opportunity；
- 重复event_id只产生一个BusinessFact和Outcome；
- 同版本Plan/Content/Strategy插入被数据库拒绝并正确转换响应；
- 外键/完整性错误不会留下半成数据；
- upgrade→downgrade→upgrade通过。

## 6. 企微契约测试

- 创建群发任务后的状态语义正确；
- 成员确认回调幂等；
- UNKNOWN不重发；
- token过期刷新一次；
- 频控不盲目重试；
- 无好友关系永久失败；
- 回调签名无效被拒绝；
- 相同幂等键不创建第二次发送。

## 7. Outbox/Job测试

- 业务事务回滚时Outbox不发布；
- 业务提交后事件最终发布；
- 两个worker不会同时执行同一Job；
- lease超时可被其他worker接管；
- 达到重试上限进入死信；
- 人工重放保留审计；
- 进程重启任务不丢失。

## 8. Connector测试

- 全量与增量同步；
- cursor断点恢复；
- Webhook丢失后增量补偿；
- 取消、软删除、退款；
- 每租户游标隔离；
- 字段映射失败可定位；
- 对账差异定位到ID；
- 重复数据幂等。

## 9. 最终命令

必须报告并通过：

```powershell
backend\.venv\Scripts\python.exe -m pytest backend\tests -q
backend\.venv\Scripts\python.exe -m alembic upgrade head
backend\.venv\Scripts\python.exe -m alembic downgrade <修复前revision>
backend\.venv\Scripts\python.exe -m alembic upgrade head
pnpm --dir frontend run build
```

另外执行：

- 前端默认密钥静态扫描；
- Alembic/模型告警检查；
- OpenAPI生成；
- 两组织跨租户安全套件；
- 模拟诊所SaaS→RevOS→审核→企微→Outcome→Attribution端到端套件。

## 10. 复审通过标准

所有P0/P1关闭；全部旧测试和新增测试通过；前端构建通过；迁移循环通过；无默认密钥进入前端；无旧调度绕过审核；对照组口径正确；一笔收入不重复归因；关键任务重启不丢失。
