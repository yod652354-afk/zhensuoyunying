# Pilot Kit v0.9（试点门店入门包）
> 对应《项目计划书 V4.1》§4 试点设计与 §19 交付物。30 家试点（Pilot A 10 家 → Pilot B 追加 20 家 → Growth Subset 5–10 家）。

## 一、试点准入（门店需满足）
1. 连续经营 ≥6 个月
2. ≥500 名可识别历史客户
3. 可提供 6–12 个月 到店/交易/预约/回访 数据（Excel/CSV/API）
4. ≥1 名员工可执行 SOP；老板/店长每周参与复盘
5. 签署试点与数据处理文件；执行脱敏、授权与免打扰规则

## 二、接入清单（数据团队）
- [ ] 患者主档：姓名/手机号/性别/生日/来源/首次与最近到店/累计次数/累计消费
- [ ] 到店：到店时间/医生/项目大类/初诊标志
- [ ] 交易：订单金额/支付金额/退款（时间、金额）
- [ ] 预约：预约时间/状态（含 no_show）
- [ ] 套餐：购买/总次数/已用/剩余/到期
- [ ] 回访：原因/渠道/员工/结果（如有）
- 导入方式：CSV 模板（前端「数据导入与质量」页下载）或 REST API
