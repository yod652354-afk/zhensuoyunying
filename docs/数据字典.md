# ClinicOS 数据字典 v1（对应需求规格 §4 与 §8.1）
> 版本：v1.0 ｜ 用途：数据导入、试点联调、字段口径统一。全部时间戳为 UTC（API 输出 ISO 8601）；ID 格式 `<前缀>_<uuid>`。

## 六张基础表（规格 8.1）
| 表 | 核心字段 | 用途 |
|---|---|---|
| Customer(Patient) | patient_id, first_visit_date, last_visit_date, total_visits, total_revenue, contact_status, consent_status, dnc, complaint_flag | 客户主档/分群 |
| Visit | visit_id, patient_id, visit_at, first_visit_flag, doctor_id, service_category, visit_status | 到店与复诊漏斗 |
| Transaction(Order/Payment/Refund) | order_id, final_amount, payment_id, amount, refund_id, refund_amount | 收入与 LTV |
| Appointment | appointment_id, patient_id, appointment_at, status, no_show | 预约与履约 |
| Followup | followup_id, patient_id, staff_id, reason, channel, status, result | 执行与触达 |
| Campaign | campaign_id, type, target_segment, budget, status | Growth 归因 |

## 关键状态枚举（规格 §8）
| 对象 | 枚举 |
|---|---|
| appointment.status | created / confirmed / rescheduled / cancelled / no_show / completed |
| visit.visit_type | first_visit / followup / treatment / review / consultation / other |
| treatment_plan.status | active / completed / paused / cancelled |
| order.status | pending / paid / partially_refunded / refunded / cancelled |
| payment.status | pending / succeeded / failed / reversed |
| package.status | active / completed / expired / refunded / paused |
| followup.reason | post_visit_care / revisit_reminder / no_show / treatment_interruption / sleeping_customer / package_expiry / campaign / complaint / other |
| followup.result | no_answer / invalid_contact / replied / not_interested / interested / appointment_created / visited / converted / do_not_contact |
| task.type | recovery / retention / growth / appointment / followup / manager_review / doctor_action |
| task.status | pending / in_progress / completed / cancelled / failed |
| experiment.group | control / treatment_a / treatment_b / treatment_c |
| task.review_status | pending（待审核）/ approved（已通过）/ rejected（退回重做） |
| task.suggested_channel | phone / sms / wechat / enterprise_wechat（AI 建议渠道） |
| user.role | boss（老板）/ staff（员工）/ admin（管理员） |
| customer.status | active / sleeping / lost / new / blocked(DNC) |
| customer.stage | first_visit / revisit / treatment / completed / dormant |

## 增量同步与回溯
- 列表 API 支持 `created_since / updated_since / cursor / limit / include_deleted`（规格 5.4）
- 历史回溯 ≥24 个月；每天可按门店对账（患者数/到店/订单金额/退款金额，差异定位到 ID）

## 任务（tasks）扩展字段（任务闭环 v2）

| 字段 | 说明 |
|---|---|
| suggested_channel / suggested_at | AI 建议渠道与时间（谁看诊谁负责生成时附带） |
| message_template_id | 关联话术模板 |
| feedback_note / feedback_images | 员工执行反馈（文字 + 图片 URL 列表） |
| review_status | pending / approved / rejected（老板审核） |
| reviewed_by / reviewed_at / review_note | 审核留痕 |
