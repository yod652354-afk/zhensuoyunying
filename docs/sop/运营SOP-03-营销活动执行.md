# SOP-03 营销活动执行 SOP（v0.9）
> 对应《项目计划书 V4.1》§10.3；系统支持：Campaign + 受众 + 实验分组 + 内容审批 + 归因。

## 流程
| 步骤 | 标准动作 | 系统支持 |
|---|---|---|
| 目标 | 先定义增量预约/到店/收入/毛利，不以"发了多少内容"为目标 | 实验 primary_metric |
| 客群 | 明确分群、排除 DNC 和不适宜人群 | 活动受众 + 实验分组（control/treatment） |
| 方案 | Always-on 或 Campaign；设置预算和产能约束 | Campaign 创建（预算字段） |
| 内容 | 生成 → 风险扫描 → 人工审批 → 发布留痕 | 「合规审计→营销内容审批」（风险规则扫描 + 审批留痕） |
| 实验 | A/B/Control 或阶段性 holdout | 「实验与增量归因」分组 |
| 执行 | 任务到人、时间、渠道；记录结果 | 今日任务 + Touch 记录 |
| 归因 | 计算增量而非总回款 | Campaign 级归因（control vs treatment）+ 显著性检验 |
| 复盘 | 沉淀 Action→Outcome 并决定是否规模复制 | 每周复盘（保留/淘汰动作） |

## 内容合规红线（系统扫描规则，正式商用需法律审查）
- 绝对化疗效承诺（根治/治愈/百分百等）— 高风险
- 医疗广告违禁词（最先进/祖传秘方等）— 高风险
- 诱导就医/夸大（免费治疗/无效退款等）— 中风险
- 促销敏感（限时抢购/最后一天等）— 低风险
- 命中任何规则都必须人工审批后才能发布；审批留痕（reviewed_by/note/时间）
