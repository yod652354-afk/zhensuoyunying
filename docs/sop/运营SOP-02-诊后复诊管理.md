# SOP-02 诊后复诊管理 SOP（v0.9）
> 对应《项目计划书 V4.1》§10.2；系统支持：诊后计划/建议、超期预警、自动任务引擎、过程漏斗。

## 节点与标准动作
| 节点 | 标准动作 | 系统支持 |
|---|---|---|
| 离店前 | 确认后续建议明确；可适用时锁定下一次预约 | 诊后计划（建议窗口 min/max 日期）+ Care Recommendation |
| 诊后 | 按项目配置关怀/提醒窗口 | 话术模板（复诊提醒·短信） |
| 预约前 | 提醒并确认履约 | 手动触达（Touch 记录） |
| No-show | 记录原因并按规则二次干预 | 「触发 Retention 引擎」自动生成 no_show 挽回任务 |
| 超期 | 进入复诊预警；达到阈值转 Recovery | 超期复诊预警 + 自动生成 overdue_revisit 任务 |
| 疗程中断 | 套餐剩余>0 且超期 | 自动生成 treatment_interruption（Recovery）任务 |
| 合理终止 | 记录原因，不计入经营性流失 | 患者标签/阶段管理 |
| 每周复盘 | 按医生/员工/节点找漏损 | 「经营报表」按医生/员工维度漏斗 + 漏损节点 |

## 关键指标
- 调整后复诊率（剔除合理流失）
- 漏损节点排序（建议→预约→履约→复诊）
- 医生建议率（<30% 标记异常，系统自动 flag）
