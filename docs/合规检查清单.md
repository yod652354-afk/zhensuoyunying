# ClinicOS 合规检查清单（Pilot 准入用）
> 对应《项目计划书 V4.1》§13 安全与合规工作流。正式商用前必须由专业法律/安全团队审查。

## 数据导入
- [ ] 最小化：只收集经营所需字段，不复制完整 HIS/病历
- [ ] 脱敏/伪名化：境外研发默认不可见真实可识别数据
- [ ] 权限审批与用途记录（来源/用途登记）

## 授权与免打扰（P0）
- [ ] 每个客户记录 consent_status（granted/denied/unknown）
- [ ] DNC 全局生效：任何营销队列自动排除
- [ ] 投诉客户标记并停止触达
- [ ] 明确拒绝后全局停止（do_not_contact 结果联动）

## 营销触达
- [ ] 每客户频控（14 天 1 次）
- [ ] 内容风险扫描 → 人工审批 → 发布留痕（系统已实现）
- [ ] 渠道规则（短信需退订通道）

## 医疗与敏感数据边界
- [ ] MVP 默认不采完整病历/诊断/处方
- [ ] 确需处理时做必要性、授权与专项合规评估
- [ ] 中国境内数据面：生产数据境内存储与处理

## 跨境（如采用境外研发）
- [ ] 境外默认使用模拟/脱敏数据
- [ ] 传输前由专业团队专项评估（PIPL）

## 试点门店准入（结合 §4.1）
- [ ] 连续经营 ≥6 个月；历史客户 ≥500 名可识别客户
- [ ] 可提供 6–12 个月到店/交易/预约/回访数据
- [ ] 至少 1 名员工可执行 SOP；老板/店长每周参与复盘
- [ ] 签署试点/数据处理文件并执行脱敏、授权及免打扰规则
